02 / ACCOUNTING RULES

Know what a number means

  • One event, one record. Ethereum chain ID, transaction hash and log index define the unique event.
  • Native token units. USDC and USDT keep their own quantities. No automatic one-dollar conversion.
  • Boundary flow. Inflow crosses into a category; outflow crosses out. Same-category movements remain in the matrix.
  • Special events. Zero-address, self and zero-value events are reported separately, excluded from the main matrix.
  • Missing means missing. Only source-complete hours receive zero values. Data gaps stay null.
  • Coverage is partial. Unknown means insufficient attribution, not an ordinary user or a payment.
