# Internal data contract v1

This is a development handoff, not a research finding. All time strings are UTC ISO-8601. Snapshot root contains `manifest.json`, `hourly.parquet`, `edges.parquet`, `totals.parquet`, `labels.json`, optional `evidence.json`. Money is six-decimal native token units, never automatically USD.

`hourly.parquet`: hour, token (USDC/USDT), category (cex/dex/lending/bridge/unknown), inflow_raw/outflow_raw decimal integer strings, inflow/outflow finite nonnegative float values for modeling, inflow_count/outflow_count integer, active_senders/active_receivers integer, complete bool. Rows are a complete hourly grid for covered categories; missing source coverage = complete false and numeric values null. Unknown participates in accounting but is not modeled.

`edges.parquet`: date (YYYY-MM-DD), token, from_category, to_category, treatment (boundary/same_category/internal/self/zero_address/zero_amount), amount_raw integer string, amount float, transfer_count integer. Every transfer belongs to one treatment; precedence zero_address, self, zero_amount, internal, same_category, boundary. Main matrix excludes zero_address/self/zero_amount; display can toggle internal. Categories are unique at each endpoint; conflicting labels become unknown.

`totals.parquet`: hour, token, amount_raw string, amount float, transfer_count, known_amount_raw string, known_amount float, complete bool. Totals cover exactly nonzero, non-self, non-zero-address transfers INCLUDING internal. known means at least one endpoint is in a verified category. Do not sum hourly unique addresses into daily unique users.

manifest: schema_version 1, kind real/synthetic-test, start/end UTC exclusive end, categories list, source dict, complete_months list, files dict filename→SHA256; additional metadata permitted. Only real-data import/fetch sets kind real. Synthetic snapshots are test artifacts and must be loudly labeled in all reports.

labels.json: list of objects address, entity, category, source_url, retrieved_at, valid_from (nullable), valid_to (nullable), evidence (text), verified (bool). Only verified labels enter accounting. Null validity => fixed-label historical replay, not contemporary entity recognition.

Root owns common.py, analyze.py, demo.py, CLI, packaging/docs/CI/tests integration. Data agent owns fetch.py, sql generation, configs/ethereum.json, data/labels.json, docs/data-access.md and data-specific tests. ML agent owns ml.py and tests/test_ml.py. Site agent owns site.py and site.html/site.js/site.css plus tests/test_site.py.

ML API: `run_experiment(rows, manifest, output: Path, *, epochs=50, seeds=(7,42,2026), lookback=168) -> dict`. Write metrics.json, predictions.parquet, anomalies.json, *.pt checkpoints, preprocessing.json, training.json. Return JSON-serializable dict with status, metrics (list), best_baseline, models, split_boundaries, anomalies (list), features. Predictions: hour, token, category, split (validation/calibration/test), model, seed (nullable for baselines), actual_inflow/outflow, predicted_inflow/outflow, residual_inflow/outflow, anomaly bool (test main seed only), score. Main model `gru` seed42; ablation `gru_flow_only` seed42. Metrics entries model, seed, split, token, category, direction, mae, wape (null if zero denominator), log_mae. Additional macro summary welcome. Missing windows skip ALL models; at least 6 calendar months required outside tests.

Site API: `build_site(snapshot: Path, analysis: dict, experiment: dict, output: Path) -> Path` reads parquet from snapshot and generates self-contained index.html plus CSV downloads. analysis contains manifest, totals (daily list date/token/amount/known_amount/coverage), edges (normalized snapshot rows), hourly (snapshot rows), quality (dict), findings (list of generated text). experiment shape above; status may be pending or complete.
